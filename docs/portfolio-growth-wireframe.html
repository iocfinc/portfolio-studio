Foreground versus background

Foreground: CEO / Chief Architect decisions

  • Approve positioning, sitemap, services stance, and tone.
  • Approve public-safe boundaries for workplace-adjacent writing.
  • Pick flagship proof pieces and reject weak narratives.
  • Review visual direction before agents implement broad changes.
  • Decide when a draft becomes public versus stays private.

Background: agent-owned execution

  • Audit links, routes, stale claims, screenshots, and mobile states.
  • Draft PRD/ADR/BDD/WTF packets from approved strategy.
  • Generate page skeletons, content calendars, and Linear seeds.
  • Run route smoke, link checks, visual checks, and build commands.
  • Loop on failures until blocked by an explicit decision boundary.
